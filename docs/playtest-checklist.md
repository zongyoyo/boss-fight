# OIIA 貓 Boss 戰試玩檢查表（T10）

目標：完整打通 3 次，每次通關時間 4–5 分鐘（企劃書估算第一階段約 2 分鐘、第二階段約 2–2.5 分鐘）。
這份表是給試玩的人邊打邊勾的；數值都是 2026-10-23 資產裡的值，調整後以 F12 面板顯示的為準。

## 試玩前準備

1. 開 `Assets/Scenes/BossArena.unity`，按 Play。第一次要看完開場；之後用勝敗畫面的按鈕或 F5 重試，開場可以長按 Space 跳過。
2. **F12 平衡面板**（左側）：
   - 打開時遊戲暫停、游標放開、角色不會動；再按 F12 關掉就繼續（面板下方可以取消「開著面板時暫停」）。
   - 「計時」分頁：第一階段、轉階段、第二階段（強化／大迴旋／狂暴）、總時間；各階段造成的傷害與 DPS；盾反、頭暈、處決、被打中、受傷、骨頭次數；「這次頭暈前靠盾反幾次、輕攻擊幾下、重攻擊幾下」。
   - 「Boss」「階段」「招式」「玩家」分頁：滑桿或 −／+ 改數值，**立刻生效**；改過的欄位變黃並顯示原值。冷卻在那一招下一次結束時才用新值計算。
   - 改的是記憶體裡的複本，**不會改到 .asset**；重試後保留，離開 Play 模式就沒了。想留下來才按「存回 .asset」（要按兩次確認）。
   - 「複製調整清單與紀錄」：把改過的數值與這次 Play 每一場的紀錄複製到剪貼簿，直接貼給 Claude。
   - 面板關著時右下角有計時條。每場結束時 Console 會寫一行 `[Balance] 第 n 次 勝利｜總 …`；每次頭暈會寫一行 `[Balance] 頭暈 #n：這次靠盾反 …`。
3. 其他 Debug 鍵：F1 Boss 血量 → 下一門檻 + 1、F2 玩家無敵、F3 指定下一招、F4 Boss 面板（右上）、F5 重試、F6 擊倒 Boss、F7 玩家倒下。**量通關時間的那 3 場不要用 F1／F2／F6**。

## 回報格式

每場貼 Console 的 `[Balance]` 那一行（或面板的「複製調整清單與紀錄」），再加上下面各表勾不起來的項目與感想。例如：

```text
第 1 次 勝利｜總 4:41.2｜第一階段 2:20.5（DPS 7.1）｜轉階段 0:05.0｜第二階段 2:15.7（DPS 4.4；大迴旋 0:08.3、狂暴 0:41.0）｜盾反 9、頭暈 3、處決 2｜被打中 14 次、受傷 260、骨頭 用 3／得 2｜調整 0 項
- 魔法陣落雷的紅圈在第二階段看不清楚
- 龍捲風太煩，冷卻想拉長
```

## 2. 每招的預兆與破綻

「破綻夠不夠打一套」的意思是：躲過或擋下之後走過去，來不來得及打完三段（或一發重擊）。
